# אפליקציית צ'אט עם מודל שפה

## תיאור הפרויקט

בפרויקט זה פותחה אפליקציית צ'אט פשוטה, המתקשרת עם מודל השפה GPT-5-NANO באמצעות ה־API של המכללה.

האפליקציה מאפשרת למשתמש לכתוב הודעות, לשלוח אותן למודל, לקבל תשובה ולהציג את היסטוריית השיחה.

## רכיבי הפרויקט

הפרויקט כולל:

- צ'אט בסיסי דרך שורת הפקודה באמצעות הקובץ chat_cli.py.
- אפשרות בחירה בין צ'אט רגיל לבין מצב Agent.
- ממשק משתמש ויזואלי באמצעות Streamlit בקובץ app.py.
- שמירת היסטוריית שיחה במהלך השימוש.
- תמיכה בעברית ובאנגלית.
- שימוש במפתח API באמצעות קובץ .env.
- הפרדה בין קבצים רגישים לבין קבצים שמועלים ל־GitHub.

## דרישות מערכת

כדי להריץ את הפרויקט נדרש:

- Python 3.10 ומעלה.
- התקנת הספריות המופיעות בקובץ requirements.txt.

הספריות המרכזיות בפרויקט הן:

- requests
- streamlit
- python-dotenv

## התקנת הספריות

יש להריץ את הפקודה הבאה בטרמינל:

`pip install -r requirements.txt`

## הגדרת מפתח API

יש ליצור קובץ בשם .env בתיקיית הפרויקט.

בתוך הקובץ יש להכניס את מפתח ה־API בצורה הבאה:

`IAC_API_KEY=your_api_key_here`

חשוב: אין להעלות את קובץ .env ל־GitHub, מכיוון שהוא מכיל מפתח אישי וסודי.

## הרצת הצ'אט דרך שורת הפקודה

כדי להריץ את הצ'אט הבסיסי יש להשתמש בפקודה:

`python chat_cli.py`

לאחר ההרצה ניתן לבחור מצב עבודה:

- 0 עבור צ'אט רגיל באמצעות Chat Completions.
- 1 עבור מצב Agent באמצעות Responses API.

כדי לצאת מהצ'אט יש לכתוב:

`exit`

## הרצת אפליקציית Streamlit

כדי להריץ את הממשק הוויזואלי יש להשתמש בפקודה:

`streamlit run app.py`

לאחר ההרצה תיפתח האפליקציה בדפדפן בכתובת מקומית, בדרך כלל:

`http://localhost:8501`

## מבנה הפרויקט

- chat_cli.py
- app.py
- get_api_key.py
- requirements.txt
- .gitignore
- README.md
- .env

## הסבר קצר על הקבצים

- chat_cli.py – קובץ הצ'אט הבסיסי שפועל דרך שורת הפקודה.
- app.py – קובץ הממשק הגרפי שנבנה באמצעות Streamlit.
- get_api_key.py – קובץ המשמש לקבלת מפתח API מהמכללה.
- requirements.txt – קובץ הכולל את הספריות הדרושות להרצת הפרויקט.
- .gitignore – קובץ שמונע העלאה של קבצים רגישים או מיותרים.
- .env – קובץ סודי שבו נשמר מפתח ה־API, ולכן אינו מועלה ל־GitHub.

## אופן העבודה הכללי של המערכת

המשתמש כותב הודעה בממשק הצ'אט.

ההודעה נשלחת באמצעות בקשת API לשרת המכללה.

המודל GPT-5-NANO מעבד את ההודעה ומחזיר תשובה.

התשובה מוצגת למשתמש בממשק, ונשמרת כחלק מהיסטוריית השיחה.

## טיפול בשגיאות

בפרויקט קיימת בדיקה בסיסית של שגיאות, לדוגמה:

- בדיקה האם מפתח ה־API נטען כראוי.
- בדיקה האם התקבלה תשובה תקינה מה־API.
- הצגת הודעת שגיאה במקרה של בעיית התחברות או מפתח לא תקין.
- מניעת העלאת קובץ .env ל־GitHub באמצעות .gitignore.
